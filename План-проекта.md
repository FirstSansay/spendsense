# 📋 Пошаговый план: AI-ассистент для управления личными финансами

**Конечный результат:** Telegram-бот с приёмом расходов через текст, голос и фото чеков, автокатегоризацией через ИИ, отчётами и рекомендациями.

**Оценка:** ТЗ — 20, MVP — 40, GitHub — 20, визуал — 10, промпты — 10. Минимальный зачёт: 60 баллов.

---

## Дни 1–2: Идея и ТЗ

1. **Зафиксировать формат:** Telegram-бот на Python (aiogram 3) + база данных + AI API.
2. **Определить MVP-функционал:** добавление расхода текстом → автоматическая категоризация ИИ; голосовой ввод; фото чека (OCR); отчёт за неделю/месяц; настройка бюджета.
3. **Составить ТЗ** с обязательными разделами: название+описание, целевая аудитория и боли, функциональные требования, ограничения и риски, метрики успеха (например, «95% расходов категоризируются верно»).
4. **Прописать план на 10 дней** и разделить функционал на «обязательный MVP» и «если успею» (голос, чеки — по желанию).

## День 3: Инструменты и окружение

- Создать бота через `@BotFather`, получить токен.
- Завести репозиторий на GitHub (позже GitFlic) — сразу с `.gitignore` и `README.md`.
- Структура проекта: `bot.py`, `db.py`, `ai_service.py`, `handlers/`, `.env` для секретов.
- Стек: Python, aiogram, SQLite → PostgreSQL, API ИИ (OpenAI / GigaChat), `pytesseract` + `speech_recognition`.

## День 4: Промпты (старт библиотеки)

- Собрать и протестировать промпты: системный промпт категоризации (вход — фраза, выход — JSON: категория, сумма, дата); промпт парсинга голоса и чека; промпт рекомендаций по экономии.
- Завести документ **«Библиотека промптов»** (пополняется весь проект).

## Дни 5–6: Разработка MVP

- База данных: таблицы `users`, `categories`, `transactions`.
- Команды: `/start`, `/add 250 кофе`, `/report`, `/budget 30000`.
- AI-категоризация покупок (текст → категория + сумма).
- Отчёт за период с графиком расходов по категориям.
- Если останется время: голосовой ввод и OCR чеков.

## Дни 7–8: Тестирование

- Прогнать все базовые сценарии: добавление, категоризация, отчёт, бюджет, ошибки ввода (кривые суммы, пустые сообщения).
- Исправить баги, снять **скриншоты/скринкаст** всех ключевых функций.

## Дни 9–10: Сборка и сдача

- Оформить `README.md`: описание, схема работы, инструкция по запуску, скриншоты.
- Развернуть бота (контейнер/сервер) для демо-доступа.
- Дописать библиотеку промптов, положить все материалы в репозиторий.
- Отправить ссылки и визуальные материалы в окно ДЗ.

---

**Приоритеты:** сначала «текст + категоризация + отчёт + бюджет» — это закрывает основную оценку за MVP. Голос и OCR чеков добавляй в последнюю очередь, они не критичны для зачёта.
