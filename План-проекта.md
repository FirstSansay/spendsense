# 📋 Пошаговый план: SpendSense — AI-ассистент для управления личными финансами

**Конечный результат:** Telegram-бот с приёмом расходов через текст, голос и фото чеков, автокатегоризацией через ИИ, отчётами, бюджетом и рекомендациями.

---

## Этап 1: Идея и ТЗ (Дни 1–2)

1. **Зафиксировать формат:** Telegram-бот на Python (aiogram 3) + база данных + AI API.
2. **Определить функционал:** добавление расхода текстом → автоматическая категоризация ИИ; голосовой ввод; фото чека (OCR); отчёт за неделю/месяц; настройка бюджета; рекомендации по экономии.
3. **Составить ТЗ** с обязательными разделами: название и описание, целевая аудитория и боли, функциональные требования, ограничения и риски, метрики успеха (например, «95% расходов категоризируются верно»).
4. **Прописать этапы и сроки** и разделить функционал на «обязательное ядро MVP» и «доработку».

## Этап 2: Инструменты и окружение (День 3)

- Создать бота через `@BotFather`, получить токен.
- Завести **основной репозиторий на GitFlic** (ветка master) — сразу с `.gitignore` и `README.md`. Вся разработка и история версий ведутся в нём.
- Структура проекта: `bot.py`, `config.py`, `db.py`, `ai_service.py`, `handlers/`, `prompts/`, `docs/`, `requirements.txt`, `.env.example` (+ локальный `.env` с секретами).
- Стек: Python · aiogram 3 · SQLAlchemy (SQLite → PostgreSQL) · AI API (OpenAI / GigaChat) · SpeechRecognition (голосовой ввод) · pytesseract (OCR).
  - ⚠️ `pytesseract` — это только Python-обёртка: в системе должен быть установлен бинарник `tesseract-ocr` (желательно с русским языковым пакетом), иначе OCR чеков не заработает.

## Этап 3: Промпты (День 4)

- Собрать и протестировать промпты:
  - системный промпт категоризации (вход — фраза, выход — JSON: категория, сумма, дата);
  - промпт парсинга голосового сообщения (транскрибация → сумма + описание);
  - промпт распознавания чека;
  - промпт рекомендаций по экономии.
- Все промпты складывать в документ **«Библиотека промптов»** — `docs/prompts.md` (пополняется на протяжении всего проекта).

## Этап 4: Разработка ядра MVP (Дни 5–6)

- База данных: таблицы `users`, `categories`, `transactions`.
- Команды: `/start`, `/add 250 кофе`, `/report`, `/budget 30000`.
- AI-категоризация покупок (текст → категория + сумма).
- Отчёт за период с графиком расходов по категориям.
- Настройка бюджета и контроль трат.

## Этап 5: Голосовой ввод и OCR чеков (Дни 7–8)

- **Голосовой ввод (ключевая фича проекта):** транскрибация голосового сообщения через AI (Whisper / speech API), извлечение суммы и описания, подтверждение транзакции перед сохранением.
- Фото чеков: OCR через `pytesseract`, извлечение покупок из текста чека, сохранение через AI-категоризацию.

## Этап 6: Тестирование (Дни 8–9)

- Прогнать все базовые сценарии: добавление текстом, категоризация, голосовой ввод, отчёт, бюджет, некорректный ввод (кривые суммы, пустые сообщения).
- Исправить баги, снять **скриншоты/скринкаст** всех ключевых функций.

## Этап 7: Финальная сборка и публикация (Дни 9–10)

- Оформить `README.md`: описание, схема работы, инструкция по запуску, скриншоты.
- Развернуть бота (контейнер/сервер) для демо-доступа.
- Дописать библиотеку промптов `docs/prompts.md`.
- Опубликовать финальную версию: основной репозиторий — **GitFlic**; на последнем этапе продублировать проект на **GitHub** и предоставить ссылку на него.

---

**Приоритеты:** сначала ядро — «текст + категоризация + отчёт + бюджет», на нём держится работоспособность продукта. Затем голосовой ввод (оставляем как ключевую фичу), после него — OCR чеков.
