## 1. Юнит-тесты (автоматические)
Запуск: `python -m unittest discover tests -v` - **16 тестов, все зелёные**. Выполняются без сети и ключей (чистые функции и слой БД):

| Модуль | Что проверяет |
|---|---|
| `tests/test_db.py` | категории по умолчанию, создание пользователя (идемпотентность), авто-создание категории, сводка/итог за месяц, изоляция периодов, бюджет и остаток, границы декабря |
| `tests/test_helpers.py` | парсинг суммы (округление, мусор), парсинг даты (fallback на сегодня), пересчёт итога чека с количеством/весом, фильтрация позиций, эвристика "похоже на чек" |

Тест-этап подключён в CI (`gitflic-ci.yaml`: build → **test** → deploy): юнит-тесты гоняются на каждом пуше в `master`.

## 3. KPI (метрики успеха из ТЗ)
Финальный контрольный замер - 10 фраз через `deepseek/deepseek-v4-flash` (OpenRouter):

| Метрика | Значение | KPI | Статус |
|---|---|---|---|
| Точность категоризации | **10/10 = 100%** | ≥ 90% | ✅ |
| Скорость ответа | медиана **2.47 c**, среднее **3.02 c** | ≤ 3 c (среднее) | ✅ на грани |
| Стабильность | **35 транзакций** без падений | 30+ | ✅ |
| Экономичность | **$0.000025 / категоризация** (183 входа/80 выхода токенов) | ≤ $0.00005 | ✅ в 2 раза ниже |
| Деплой | бот отвечает на сервере (поллинг, БД в томе) | стабильная работа | ✅ |

Замечание по скорости: медиана стабильно **< 3 c**; выбросы до 7–11 c возникают при нестабильности VPN-туннеля на сервере. На устойчивом канале среднее держится в норме.

## 4. Оптимизации, внесённые по итогам тестов
- **Повтор запроса категоризации** при "пустом" ответе модели (единичные сбои не роняют точность - исправило кейс "лекарства в аптеке 340").
- **Таймаут 30 c и один retry** в клиенте OpenRouter - зависшие запросы не блокируют бот и не раздувают среднее время.
- **Строже эвристика "похоже на чек"** (требуются буквы + цифры) - чистые числа не отправляются в парсер.
- HTTP/2 к OpenRouter **не дал выигрыша** - задержку определяет сетевой канал, а не протокол (замер: медианы 2.75 vs 2.66 c).

## 5. Проверка прод-среды
- Деploy через GitFlic CI/CD (build → test → deploy) проходит успешно; контейнер `spendsense-bot` в статусе Up.
- В контейнере присутствуют ffmpeg 7.1.5 и tesseract-ocr (rus) - голосовые и чеки обрабатываются.
- БД SQLite лежит на постоянном томе `/app/data/spendsense.db` (переживает пересборки).
